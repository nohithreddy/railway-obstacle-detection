# Final-Year B.Tech Project Report

## Title

Railway Obstacle Detection and Intelligent Train Control System

## Problem Statement

Develop a real-time AI and IoT-based railway safety solution that detects obstacles on tracks, estimates collision risk, assists the driver, notifies the control room, and initiates emergency braking for high-risk obstacles.

## Objectives

- Detect humans, animals, vehicles, fallen trees, rocks, debris, and track damage.
- Estimate obstacle distance, size, speed, and track position.
- Classify risk into small, medium, and large categories.
- Provide driver alerts and control-room notifications.
- Visualize train, track, obstacle, detection range, and braking distance in 3D.
- Store event logs, sensor evidence, driver actions, and brake events.

## Modules

1. Sensor acquisition module.
2. AI detection and tracking module.
3. Distance and size estimation module.
4. Decision engine.
5. Driver assistance dashboard.
6. Railway portal API.
7. Emergency braking module.
8. Notification module.
9. Event logging module.

## Tools and Technologies

Python, FastAPI, OpenCV, YOLOv8, DeepSORT, MQTT, PostgreSQL, MongoDB, React, Three.js, Java Spring Boot, AWS/Azure.

## Conclusion

The project demonstrates a practical intelligent railway safety system with real-time obstacle classification, decision support, visual monitoring, and emergency response simulation.
